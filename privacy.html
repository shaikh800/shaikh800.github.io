Privacy Policy

Last updated: October 20, 2026

This site (mdshaikh.me) is the personal portfolio and academic-tools site of Md. Shaikh Alam. It includes a Civil Engineering resource section, a 3D portfolio, an Academy section and a Research Hub. This page explains what information the site collects, why, and how it's used — mainly relevant to the Research Hub's sign-in and the "Sign in with Google" upload feature.

Account sign-in (Research Hub)

To use the Research Hub, you sign up with your email address and a password of your choosing. The password is never stored in plain text — only a one-way hash of it is kept. Your email is used to identify your account and to let the site admin approve access to shared research materials.

Signing in with Google

The Team Uploads feature on the Research Hub offers an optional "Sign in with Google" button so you can upload your own files. If you use it, the site requests the following permissions through Google's sign-in:

  • Your name, email and profile picture — shown next to files you upload, so teammates know who shared what.
  • Google Drive "drive.file" access — this is a restricted, per-file permission: it only lets the site create and access files that you upload through it. It cannot see, read or modify any other file already in your Google Drive.

You can revoke this access at any time from your Google Account permissions page.

Where data is stored

Member records (email, password hash, approval status) and file metadata (file name, uploader name/email, link) are stored in a data file inside this site's GitHub repository, which only the site admin can edit. Uploaded files themselves are stored in the site admin's Google Drive, inside a folder dedicated to this site.

What this site does not do

This site does not sell or share your information with third parties, does not run advertising, and does not use your data for anything beyond the features described above.

Third-party services used

The site is hosted on GitHub Pages, uses Google Identity Services and the Google Drive API for sign-in and file uploads, and uses a small Google Apps Script backend for admin authentication.

Contact

Questions about this policy or your data can be sent to md.shaikh.alam.007@gmail.com.
