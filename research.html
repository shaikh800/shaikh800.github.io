What's real vs. what's mocked in this draft

  • Mocked: all files, folders, notices, chat messages and the member list below are placeholder data, stored only in this page's memory — reload and it resets.
  • Mocked: the Admin / Member switch (the dark button, bottom-right) just flips a demo flag. It is not a real login yet.
  • Would be real: file browser → backed by an actual Google Drive folder via the Drive API, same OAuth approach your Civil section already uses for resource uploads.
  • Would be real: notices + chat → saved through a small Google Apps Script endpoint (same pattern as your Academy admin panel / exam controller) that reads and writes a file inside that Drive folder, so everything still lives in Drive, not a database.
  • Would be real: Admin control → only you hold the real admin password (checked on the server, like admin_panel.html already does — not the weaker local check civil.html currently uses, see the bug notes). Friends get view or download rights per-person from the Members panel.
