How to get the API key (free, 2 minutes)
  1. Open Google Cloud Console → Drive API (same project your Drive upload button already uses) and click Enable.
  2. Go to APIs & Services → Credentials → Create Credentials → API key.
  3. Click the new key → Restrict key: under "API restrictions" pick Google Drive API only; under "Application restrictions" pick Websites and add mdshaikh.me/*.
  4. Copy the key and paste it above, then Save.
